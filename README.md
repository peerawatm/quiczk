## TOML parsing format

```toml
[config]
shuffle_questions = false
shuffle_options = false
random_start_cursor = false
hide_options_until_interact = true
question_timer_seconds = 15

[quiczk]
q1 = "Who is the author of quiczk?"
o1 = [
  "Linus Benedict Torvalds",
  "Peerawat Monviset",
  "Augusta Ada King, Countess of Lovelace",
  "Alan Mathison Turing",
]
a1 = "Peerawat Monviset"

q2 = "How do you exit Vim?"
o2 = [
  ":wq",
  "buy a new laptop",
  "pull the power plug",
  "turn off the breaker",
]
a2 = ":wq"
e2 = "':wq' writes changes and quits the editor."
```

## Config

Config is optional. One file is used, chosen by the first environment variable
that is set: `XDG_CONFIG_HOME`, `HOME`, `USERPROFILE`, then `APPDATA`.

- `$XDG_CONFIG_HOME/quiczk/config.toml`
- `~/.config/quiczk/config.toml`
- `%USERPROFILE%\.config\quiczk\config.toml`
- `%APPDATA%\quiczk\config.toml`

A quiz file can embed its own `[config]`. Values merge per key, so a partial
table only overrides what it sets:

```
quiz file  >  config file  >  defaults
```

Unknown keys are an error. `question_timer_seconds` is in seconds; `0` or absent
means no timer.

| Key | Default | Effect |
|---|---|---|
| `shuffle_questions` | `false` | Randomize question order |
| `shuffle_options` | `true` | Randomize option order |
| `random_start_cursor` | `true` | Start the cursor on a random option |
| `hide_options_until_interact` | `true` | Keep options hidden until you interact |
| `question_timer_seconds` | `0` (off) | Time limit per question |

```toml
[config]
shuffle_options = false
question_timer_seconds = 30
```
